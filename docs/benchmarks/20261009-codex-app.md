# Codex Appでの4ユースケース実測（2026-10-09）

README掲載値の計測条件と算式です。元の時計記録を保持し、質問待機を差し引く定義へ変更しました。再実行による測定ではありません。

## 計測条件

- 実行クライアント：Codex App。`ema-rwe-mcp`を呼出元抽出（追加APIキーなし）で使用。サーバー側LLMとサブエージェントは使用していません。
- 呼出元モデル：4例とも **GPT-6.1 Sol（reasoning effort = medium）**。
- カタログ：2026-10-01の公式CSVスナップショット、Non-interventional study 3,314件。DARWIN EU限定なし。一次判定・比較表の上限は各5件。
- 開始：各ケースの検索を開始したクライアント時計の記録。終了：PDF解析・質問別回答保存後、`get_protocol_comparison`による最終比較JSON/Markdown出力を取得した記録。
- 質問待機：絞り込み質問の記録時刻から、回答を処理した記録時刻まで。実際の送信・受信イベントを計装した値ではありません。
- **MCP実行時間 = 検索開始から比較出力までの経過秒数 − 質問待機秒数**。元の小数秒を差し引いてから、秒へ四捨五入します。

この定義には呼出元LLMの読解、ツール操作、引用検証の失敗と再試行を含みます。質問待機中に別ケースの処理を進めたため、待機以外の別ケース処理も含みます。サーバー内部のツール実行時間の合計は未計測です。
