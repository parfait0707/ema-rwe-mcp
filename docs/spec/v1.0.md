# v1.0 追加要件：医薬品名の展開をカタログ由来の対応に一般化する

2026-10-01。v0.9 の ATC クラスの追加を置き換える。根拠の集計は `docs/validation.md`（2026-10-01、spec v1.0）を参照。

医薬品の展開が必要な理由は次の2つである。

- 利用者の入力する医薬品名は正規化されていない。一般名と製品名の対応が要る。
- 利用者がクラスで聞いてもカタログは個別の薬で書かれていることが多く、その逆もある。クラスと所属薬の対応が要る。

カタログの研究の半数以上は、医薬品をコード無しの名前で記録しているか、何も記録していない。そのため展開した語はすべて名前として検索する。ATC は名前どうしをつなぐ結合キーとしてだけ使い、ATC コードを調べる用途はこの MCP の範囲外とする。WHO ATC 索引は同梱しない。

1. **対応の材料**
   - カタログの exposures 欄の `(コード) 名称`（第2〜5レベル）。出所 `catalogue_atc`。取り込んだカタログから都度作る。
   - EMA 医薬品辞書の製品名・INN／common name・ATC。出所 `ema_medicines`。
   - 同じ研究内の併記からの推定は使わない（測定した誤対応のため）。
2. **解決**：`compare_protocols`（`match_scope=concept`）は、ブロックの各 `queries` を次のいずれかで ATC コードに解決する。
   - カタログの名称との完全一致（大文字小文字を区別しない）。
   - 第3〜5レベルの ATC コードそのもの（大文字小文字は区別しない）。カタログか EMA 辞書に、そのコードで始まるコードがある場合に限る。第2レベル（例：N03）は ICD-10 の分類と衝突するため解決しない。
   - EMA 医薬品辞書の展開（従来どおり）。
   - 複数の出所のコードが違う場合（ATC の版違い）は、すべて使う。
3. **展開**
   - 第5レベル（成分）：カタログ上の名称を固有語に、第4レベルのクラスのコードと名称をカテゴリー語に加える。
   - 第3・第4レベル（クラス）：クラスの名称と、その下にコード付けされた所属薬の名称（カタログと EMA 辞書）を固有語に加える。所属薬は、クラスに含まれる薬として検索するのであって、別の薬の同義語ではない。
   - 合わせ剤の名称は分割しない。単剤名から合わせ剤には解決しない。
   - 親のコードなしでは意味を持たない名称（`combinations`、`various`、`other(s)`）は検索語にしない。
   - 追加する固有語は1問（全ブロック合計）あたり 100 語まで。クラス自身の名称を先に、所属薬を後に加え、入りきらなかった語の数を `omitted` に返す。
4. **出所**：サーバーが加えた固有語に一致した研究は、`matched_term_sources` に `catalogue_atc` または `ema_medicines` を示す。両方にある名称は `ema_medicines` とする。呼出元がいずれかのブロックに書いた語は付け替えない。カテゴリー語は従来どおり `category`。
5. **応答**：`compare_protocols` の応答に `medicine_expansion: [{block, query, atc_codes, queries, category_terms, omitted}]` を返す。`queries` と `category_terms` は、そのブロックに実際に加えた語である。v0.9 の `atc_class_terms` は廃止する。
6. **呼出元への指示**：利用者がクラスで聞いた場合は、クラス名と第3・第4レベルの ATC コード（例：N03A）を `queries` に入れるよう指示する。どちらの出所にも無い薬は、呼出元が名前（所属薬を含む）を自分で渡す。
