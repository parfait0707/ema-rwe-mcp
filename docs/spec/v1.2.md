# v1.2 追加要件：取得で分かった事実の保存、医薬品欄の補完、類縁概念の順位付け

2026-10-02。v1.1 の残課題への対応。v1.1 に加える。

1. **取得で分かった事実（`protocol_observations`）**：PDF の取得で分かった事実は、カタログの表とは別の表に研究ごとに保存する。内容は、プロトコルが見つかったか（`protocol_found`）、テキスト層（`text_layer`）、プロトコル ID、補完した医薬品（`exposures`）である。カタログの取り込み直しや同梱 DB の入れ替えでは消えない。v1.1 で研究に記録していた `protocol_text_layer` はこの表へ移す（DB スキーマ 6）。
2. **順位付け**：プロトコルが見つからなかった研究（`protocol_found=false`）は、テキスト層の無い研究と同じく最後にする。CSV に所在が無くても、取得でプロトコルが見つかった研究（`protocol_found=true`）は後ろに回さない。候補一覧の行には `protocol_found` を返す。
3. **医薬品欄の補完（`ema-rwe backfill-protocols`）**：カタログの医薬品欄が空の研究について、利用者が実行するコマンドで補う。検索の途中では実行しない。
   - 文章からの補完（通信なし）：題名・説明・目的に書かれた既知の医薬品名（カタログの第5レベルの名称、EMA 辞書の INN と製品名）。出所 `catalogue_text`。
   - プロトコルからの補完：CSV にプロトコルの所在がある研究のプロトコルを1件ずつ取得し、PASS 情報表の「Active substance」「Medicinal product」の欄にある既知の医薬品名と ATC コード、物理ページを記録する。出所 `protocol_pass_table`。欄の自由記述は保存しない。
   - 研究と研究の間を既定で60秒空け（HTTP の間隔とは別）、試した研究は飛ばして再開でき、429 を受けたら止まる。新しい CSV を取り込んだ後に実行すると、欠けている研究だけを補う。
   - 補完した医薬品は索引の医薬品（exposure）の列に入る。カタログの値とは区別して、候補の行の `observed_exposures` に返す。
   - これは「PDF は選んだ研究についてだけ取得する」原則の例外であり、この条件の範囲でだけ許す（AGENTS.md）。
4. **同梱 DB の観測**：同梱 DB は補完の結果（`protocol_observations`）を含めて配布する。成分名・ATC・ページ番号だけで、引用文は含めない。起動時、同梱 DB の観測のうち利用者が持たないものを加える。カタログの取込日が同じでも加える。利用者自身の観測が優先される。
5. **類縁概念の検索**：類縁概念の語を1つの概念ブロックとし、通常の検索と同じ順位付け（プロトコル所在・テキスト層を含む）で並べる。0件時の候補の提示と `match_scope=analogous` の再実行の両方に適用する。一致した語の出所は、サーバーが ATC から作った語を `catalogue_atc`、呼出元の語を `caller`、辞書の語を `dictionary` とする。
6. **上位概念の補い**：0件の医薬品の類縁概念で、第4レベルのクラスに名称が無いときは第3レベルの名称を上位概念にする。
7. **塩の語**：塩・エステル・水和物の語の一覧は、カタログと EMA 辞書で「X W」と「X」がともに医薬品名として現れる語 W から作る（別の有効成分・製品を表す alafenamide、flufenamide、rinfabate、seretide は除く）。EMA 辞書の単一成分の塩付きの名前には、塩の語を除いた基名の鍵を加える。この鍵は語全体の照合にだけ使い、文中の走査には使わない。
