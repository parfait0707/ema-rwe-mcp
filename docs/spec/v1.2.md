# v1.2 追加要件：取得で分かった事実の保存、医薬品欄の補完、類縁概念の順位付け

2026-10-02。v1.1 の残課題への対応。v1.1 に加える。

1. **取得で分かった事実（`protocol_observations`）**：PDF の取得で分かった事実は、カタログの表とは別の表に研究ごとに保存する。内容は、プロトコルが見つかったか（`protocol_found`）、テキスト層（`text_layer`）、プロトコル ID、補完した医薬品（`exposures`）である。カタログの取り込み直しや同梱 DB の入れ替えでは消えない。v1.1 で研究に記録していた `protocol_text_layer` はこの表へ移す（DB スキーマ 6）。
2. **順位付け**：プロトコルが見つからなかった研究（`protocol_found=false`）は、テキスト層の無い研究と同じく最後にする。`check_protocols` の確認結果は `protocol_found` にも反映する。テキスト層は最新版の取得のときだけ記録する。CSV に所在が無くても、取得でプロトコルが見つかった研究（`protocol_found=true`）は後ろに回さない。候補一覧の行には `protocol_found` を返す。
3. **医薬品欄の補完（`ema-rwe backfill-protocols`）**：カタログの医薬品欄が空の研究について、利用者が実行するコマンドで補う。検索の途中では実行しない。
   - 文章からの補完（通信なし）：題名・説明・目的に書かれた既知の医薬品名（カタログの第5レベルの名称、EMA 辞書の INN と製品名）。出所 `catalogue_text`。
   - プロトコルからの補完：CSV にプロトコルの所在がある研究のプロトコルを1件ずつ取得し、PASS 情報表の「Active substance」「Medicinal product」の欄にある既知の医薬品名と、その名前の直後（60字以内）に書かれた ATC コード（欄に医薬品が1つだけなら欄の中のコード）、物理ページを記録する。出所 `protocol_pass_table`。欄の見出しは行頭のものだけを数え、見出しが2つ以上あるページだけを表とみなし、欄は300字までとする（本文中の語句からは補わない）。欄の自由記述は保存しない。複数語の製品名は文章からの補完に使わない。
   - 研究と研究の間を既定で60秒空け（HTTP の間隔とは別）、プロトコルを読み終えた研究（`backfill_done`）は飛ばして再開する。429 や通信障害は HTTP 層の再試行の後に止まり、その研究は次の実行で試し直す。プロトコルが無い・読めない研究、恒久的な HTTP エラー（4xx、`EMA_HTTP_ERROR`）の研究は終わったものとして記録する。`--reextract` は保存済みのプロトコルの PASS 表を通信なしで読み直す。新しい CSV を取り込んだ後に実行すると、欠けている研究だけを補う。カタログが医薬品欄を埋めた研究からは、文章由来の値を外す。
   - 補完した医薬品は索引の医薬品（exposure）の列に入る。カタログの値とは区別して、候補の行の `observed_exposures` に返す。
   - これは「PDF は選んだ研究についてだけ取得する」原則の例外であり、この条件の範囲でだけ許す（AGENTS.md）。
4. **同梱 DB の観測**：同梱 DB は補完の結果（`protocol_observations`）を含めて配布する。配る項目は `protocol_found`、`text_layer`、`exposures`（成分名・ATC・ページ番号・出所）、`backfill_done` だけで、引用文、ローカルの PDF ID、エラーは含めない。同梱 DB は、作業用 DB で補完を実行し、`ema-rwe merge-observations <作業用DB>` で同梱 DB に加えて作る（索引も作り直す）。起動時、同梱 DB の観測で、利用者の観測に無い項目を研究ごとに補う（利用者の項目が優先）。カタログの取込日が同じでも補う。文章から補った医薬品は、カタログの医薬品欄が空の間だけ索引と候補に使う。
5. **類縁概念の検索**：類縁概念の語（単語を含まない語は除く）を1つの概念ブロックとし、通常の検索と同じ順位付け（プロトコル所在・テキスト層を含む）で並べる。依頼概念にどの列でも一致する研究は除く。一致した語は元の書き方で返し、件数（`study_count`）もそれで数える。0件時の候補の提示と `match_scope=analogous` の再実行の両方に適用する。一致した語の出所は、サーバーが ATC から作った語を `catalogue_atc`、呼出元の語を `caller`、辞書の語を `dictionary` とする。
6. **上位概念の補い**：0件の医薬品の類縁概念で、第4レベルのクラスに名称が無いときは第3レベルの名称を上位概念にする。
7. **塩の語**：塩・エステル・水和物の語の一覧は、カタログと EMA 辞書で「X W」と「X」がともに医薬品名として現れる語 W から作る（別の有効成分・製品を表す alafenamide、flufenamide、rinfabate、seretide は除く）。EMA 辞書の単一成分の塩付きの名前には、塩の語を除いた基名の鍵を加える。この鍵は語全体の照合にだけ使い、文中の走査には使わない。
