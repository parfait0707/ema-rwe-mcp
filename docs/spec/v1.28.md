# v1.28 追加要件：ツールの未知の引数を断る

2026-11-20。v1.27 に加える。
MCP ツールに、スキーマに無い引数名を渡しても、検証エラーにならず黙って無視されていた（Issue #102）。FastMCP の引数モデル（`ArgModelBase`）が追加の項目を許す既定のままだったためで、呼出元が引数名を間違えても（`read_protocol_text` の `page_start` など）、既定値で処理された結果を受け取っていた。ここには、変わった挙動だけを書く。実測は[検証記録](../validation.md) の「ツールの未知の引数を断る」の節。

1. **未知の引数は断る**：全ツールで、スキーマに無い引数名を含む呼び出しは、必須の引数が無いときと同じ検証エラー（`isError=true`、エラー文に未知の引数名と `extra_forbidden`）で断り、ツールを実行しない。
2. **スキーマで伝える**：各ツールの `inputSchema` に `additionalProperties: false` を付け、クライアントが呼ぶ前に知れるようにする。
3. **変えないもの**：ツールの数、引数の名前・型・既定値、注釈、応答の形。サーバーが内部で渡す `ctx` は引数に含まれない。
