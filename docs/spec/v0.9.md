# v0.9 追加要件：医薬品の ATC 上位クラスをカテゴリー語に加える

2026-10-01、同梱カタログ（3,314 件）の集計に基づく。

- exposures 欄は医薬品を `(B01AF) Direct factor Xa inhibitors` のように「ATC コード＋名称」で記録する。この形の記載を持つ研究は 1,541 件ある。
- ATC が第2〜4レベル（クラス）だけの研究が 293 件ある。これらは成分名（例：apixaban）の検索では一致しない。
- 自由記述欄に何らかのコード体系（ICD-10、SNOMED CT、Read、MedDRA、OMOP）が現れる研究は、各 0.2〜1.3% だった。

1. **ATC クラスの追加**：`compare_protocols`（`match_scope=concept`）は、ブロックの各 `queries` を EMA 医薬品辞書で展開する。得られた第5レベル ATC の第4レベル（先頭5文字）を、そのブロックの `category_terms` に加える。
   - 加える語は、コード（例：`B01AF`）と、カタログ自身の名称（exposures 欄の `(B01AF) …` から取得。無ければ加えない）の2つである。
   - 呼出元が同じ語（大文字小文字を区別しない）を `queries` や `category_terms` に渡していれば、重複して加えない。
   - 対象は第4レベルだけとする。第3レベル以上は他の薬効群を広く含み、候補数を増やして絞り込みの質問を増やすためである。
   - EMA 医薬品辞書に無い成分（中央審査品目以外）からはクラスを導かない。
2. **扱い**：加えた語は通常のカテゴリー語と同じく、出所 `category` で順位の後方に置く。クラスを成分と同一視しない（同じクラスの別成分だけを記録した研究には一致しない）。
3. **応答**：`compare_protocols` の応答に `atc_class_terms: [{block, code, label, terms}]` を加え、サーバーが加えた語を示す。`blocks` は呼出元が渡したままの内容を返す。
4. **比較表の一致の根拠**：比較行の `match` に `sources`（語ごとの出所）を加える。カテゴリー語だけで一致した研究は「カテゴリー語だけでの一致（依頼概念そのものかはPDFで確認）」と表示し、固有語と混在する場合はカテゴリー語に「（カテゴリー語）」を付ける。
