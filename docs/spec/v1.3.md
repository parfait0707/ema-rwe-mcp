# v1.3 追加要件：PASS 情報表のクラスと ATC コード、文章からの補完の誤り防止

2026-10-03。v1.2 の医薬品欄の補完（`ema-rwe backfill-protocols`）に加える。

1. **PASS 情報表の欄のクラスとコード**：「Active substance」「Medicinal product」の欄から、既知の医薬品名に加えて、次のものを記録する（出所 `protocol_pass_table`）。欄の自由記述は、これまでどおり保存しない。
   - カタログ自身のクラス名（第2〜第4レベル。例：`DIURETICS`、`ANTIPSYCHOTICS`）。名称だけで照合し、コードは推測しない。
   - 欄に書かれた ATC コード（第2〜第5レベル）。先頭3文字の第2レベルの群が、カタログか EMA 辞書のコードにあるものだけを数える（`G12C` のような変異名は数えない）。第2レベル（`C03` など。ICD-10 の分類と同じ形）は、さらにカタログにその下位のコードがあり、欄に「ATC」の語かそのコードのカタログ上の名称が書かれているときだけ数える。空白や改行で分かれたコード（`J06B A02`）はつなげて読む。カンマで区切られたコード（`B01A, C10`）はつながない。
   - コードは、「名前 (コード)」の書式では直前の名前に付ける。欄がコードで始まり「コード (名前)」と書かれているときは、直後の名前に付ける。隣のコードを越えて名前を探さない（辞書に無い薬のコードを、隣の薬に付けない）。欄の医薬品とコードがともに1つだけのときは、その医薬品に付ける。付ける名前が無いコード（辞書に無い薬）は、カタログのそのコードの名称を名前として記録する。名称が無いか、combinations のような汎用の名称なら、コード自体を記録する。
   - クラス名の中にある医薬品名（`Platelet aggregation inhibitors excl. heparin` の heparin）は、クラスの一部として扱い、別に記録しない。
2. **名前の後に作用の語が続く場合**：既知の名前の直後に receptor(s)、inhibitor(s)、inhibition、antagonist(s)、agonist(s)、blocker(s)、blocking、blockade が続くときは、その名前の薬としない（`angiotensin II receptor blockers` は angiotensin II ではない）。PASS 表と文章の両方に適用する。
3. **文章からの補完の除外**：研究の略称（大文字の語の直後に study、trial、registry などが小文字か先頭だけ大文字で続くもの。例：`SONATA study`）と同じ名前は、その文章のどこに出ても使わない。測定される物質として書かれた名前（直前に exhaled、serum、plasma、blood、urine、urinary、直後に level、concentration）は、その箇所では使わない。
4. **商標記号**：照合の正規化で ™ と ℠ を語から切り離す（`VIZAMYL™` を vizamyl と読む）。
5. **索引**：補完した医薬品の名前に加えて、記録した ATC コードも医薬品（exposure）の列に入れる。
6. **規則の版と配布**：観測は出所ごとの抽出規則の版（`exposure_rules`。例：`{"catalogue_text": 2, "protocol_pass_table": 2}`）を持つ。同梱 DB の観測を統合するとき、同梱 DB の方が新しい規則で抽出した出所については、利用者の DB のその出所の値を同梱 DB の値で置き換える。ほかの出所と項目は、これまでどおり利用者の値を優先する。
7. **範囲外**：PASS 表の無いプロトコルの本文の ATC コードは記録しない。本文のコードは、曝露のほかに除外基準、アウトカムの定義、共変量、データ記録の例にも使われており、曝露と区別できないため（AGENTS.md：コードの一致は定義の根拠ではない）。
