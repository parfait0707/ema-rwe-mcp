# v0.4 追加要件

2026-09-14の実走（「肝障害をアウトカムとした研究」）で、8検索式の和集合が索引3,312件中1,999件になり、種別と国だけでは一次判定上限へ収束しなかった。この結果を踏まえてv0.3の次の部分を更新する。

1. **近傍一致**。複数語の検索語は同一列内で3語以内に共起した場合だけ一致する（FTS5 `NEAR`）。単語・同義語・関連語・コード表記はORで結合する。5語以上の自由文は単語へ分解する。「hepatic failure」がheart failureに一致しない。
2. **役割別の検索列**。FTSに`condition`（Medicinal condition、Additional medical condition）、`outcomes`（Outcomes）、`exposure`（INN、製品名、ATC）、`objective`（Main study objective）を追加し、DBスキーマをv4へ上げる。`search_studies`／`compare_protocols`の`role`（any／outcome／condition／exposure）で対象列をタイトルと役割列に限定する。旧DBは起動時にFTSを再構築し、役割列はexportの再取込で埋まる。
3. **候補一覧と明示選択**。`needs_narrowing`の応答に、候補数が`EMA_MAX_LISTED_CANDIDATES`（既定50）以内なら`candidates`（ID・タイトル・状態・国・種別・デザイン・疾患）を含める。`compare_protocols`は`study_ids`（候補の部分集合、一次判定上限以内）を受け付け、その研究だけを一次判定へ進める。上限超過時のPDF取得は引き続き行わない。
4. **臨床条件のfacet**。`facets.conditions`にMedicinal conditionの件数上位を返す。Study topicは区分値のため使わない。
5. **辞書の同梱**。`data/terminology.json`（日本語疾患名→英語名・関連語・WHO ICD-10 2019分類コード。出典URL付き、`verification=unverified`）をチェックアウト内の既定`EMA_TERMINOLOGY_PATH`とする。EMA公式医薬品辞書`data/ema-medicines.json`もコミットする。（**v0.6 で廃止**：疾患辞書は同梱・既定読み込みをやめ、`data/terminology.example.json` の記入例になった。EMA 医薬品辞書の同梱は継続）
6. **コンテキスト削減**。MCPの`instructions`を要点のみに短縮し、完全な手順を`docs/mcp-workflow.md`へ移す。ツール説明文を1〜3行にする。`search_studies`は既定で`detail=compact`（説明文・由来・完全な展開を省略）、`query_expansion`は要約、`catalogue`は状態・取込済み種別・更新推奨のみ。`compare_protocols`の`query_expansions`も要約にする。
7. `others`の内訳細分化は見送る（ユーザー判断）。

実測（2026-09-13 export、3,312件）: 「liver injury」1,999件→50件（近傍一致）→103件（辞書の関連語を追加）、`role=outcome`で92件。日本語「肝障害」を`role=outcome`、claims、Japanで絞ると1件（46425）。`search_studies`の応答は5件表示で約22 KB→約10 KB。
