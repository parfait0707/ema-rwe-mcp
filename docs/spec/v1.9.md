# v1.9 追加要件：医薬品名の関係、省いた所属薬、短い製品名

2026-10-08。v1.8 に加える。
根拠は [再々レビュー](../research/202610082232_pr65_pr66_rereview_implementation_plan.md) の指摘 2、3 と短い製品名の評価、[評価と実装計画](../research/202610082250_rereview_response_plan.md)。

1. **名前の関係**：カタログの ATC 名と EMA の成分名の関係を `medicine_relation` で `equivalent`、`broader`（カタログの名前が広い）、`narrower`、`different` に分ける。単語の包含と番号の規則は v1.7 のままで、番号（株、型、価数）が片方にしか無いときは、無い方を広い名前とする。
2. **広い名前は具体語にしない**：具体薬の検索で、カタログの名前が `broader` なら、検索語（`queries`）ではなくカテゴリー語（`category_terms`）に加える。`narrower` なら加えない。`pandemic influenza vaccine (H5N1) (live attenuated, nasal)` の検索では、`influenza, live attenuated` はカテゴリー語になり、季節性の弱毒生ワクチンの研究が具体語の一致として上位に並ばない。
3. **クラスの所属薬は名前の同一性と分けて見せる**：クラスの所属薬には `different` 以外の関係の EMA の記録を入れる（v1.1 の 4 のまま）。`different` で入れなかった記録は、`expand_medicine` の `omitted_members`（名前、コード、カタログの名前、理由。最大 30 件）と `omitted_members_total` で返し、`medicine_expansion` に載せる。カタログと辞書の全クラスで 86 組あり、多くは名前が ATC 名と違うだけの正当な所属薬（遺伝子組換え第 VIII 因子の INN、ワクチンの製品名など）で、一部は EMA の記録のコードの誤り（無関係な薬のコード）である。名前の字面だけでは両者を汎用的に見分けられないので、自動では加えず、呼び出し側がクラスに属すると判断したものを検索語に加えて再検索する（手順書）。
4. **短い製品名**：EMA の製品名の末尾の `(previously ...)` だけを外した名前を、名前全体の照合の別名にする。ほかの括弧は外さない。成分の組が異なる記録とぶつかる別名、既にある照合キーと同じ別名は使わない。自由文の中では探さない。
