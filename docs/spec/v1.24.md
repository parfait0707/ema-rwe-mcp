# v1.24 追加要件：採点での値の照合、誤りの検出、難しい項目

2026-11-20。v1.23 に加える。
採点（v1.20 の `extraction_eval.py grade`）は「その項目に触れているか」しか見ず、4 つの研究が満点で、版の間の差を見分けなかった。値の照合、誤りの検出、難しい項目を加える。実測は[検証記録](../validation.md) の 2026-11-20 の節。

1. **値の照合（`values`）**：正解の項目は、その項目の事実が述べるべき値（年齢の 18、期間の 12 か月、コードの C25 など）を、短いパターンの一覧 `values` として持てる。採点では、項目に一致した事実（`accept`）のうちのどれかが、各値を述べていることを求める。
   - 値は、読み手が書いた値（`value`）の中にあること。読み手の値が数字を 1 つも含まないとき（「adults」）に限り、その事実の引用の中にあればよい。「16 歳以上」と書いて「18 years」を引用した事実は、触れているが正しくない。
   - 件数は `answer_correct`、`analysis_correct`。触れているが値が無い項目は `wrong_value` に挙げる。下限 `minimum.answer_correct`（組入れ・除外基準 0.8、アウトカム 0.7）を下回ると失敗とする。
   - `check` は、各値が正解のページに書かれていることを確かめる（正解の側の誤りを防ぐ）。
2. **種類の取り違え（`misplaced`）**：正解が `kind_fields`（種類ごとの解析のブロック。組入れ基準は `cohort.inclusion_criteria`、除外基準は `cohort.exclusion_criteria`）を持つとき、項目が解析にあるのに、自分の種類のブロックに無いものを数える。`maximum.misplaced`（0）を超えると失敗とする。
3. **正解に無い事実（`extra_in_answer`、`extra_in_analysis`）**：どの項目にも一致しない事実の件数を表示し、`--verbose` で内容を挙げる。失敗にはしない（正解に無い正しい事実がある。目で見るための一覧）。
4. **難しい項目**：18 項目を加える（組入れ・除外基準 60、アウトカム 40、計 100 項目）。付録のコードリスト（研究 49324 の診断のコード、陰性対照のアウトカムのコード、研究 105807 の付録の表）、変数の定義の節にあるコードと閾値（研究 49285 の eGFR、透析の回数、ICD-10）、感度分析の表の行（研究 49324 の 5a、7a）、別の章の定義（潜伏期間）、妥当性の確認（研究 49276）、MedDRA の用語。質問への最初の検索に入ることを求めない項目（`beyond_first_search`）は、全体で 10。
5. **表示**：`grade` は、研究ごとに「回答：触れている / 引用にある / 正しい」「解析：触れている / 正しい」「取り違え」「正解に無い事実（回答 / 解析）」を 1 行で示す。`--verbose` で、欠けた項目、値の無い項目、取り違え、正解に無い事実を挙げる。
6. **変えないもの**：サーバーの動作（抽出、検索、検証）。この変更は、正解データと採点のスクリプトだけ。
