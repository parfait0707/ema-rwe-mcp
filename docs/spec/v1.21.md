# v1.21 追加要件：アウトカム定義の正解データ、質問でのプロトコル内検索の改良

2026-11-20。v1.20 に加える。
抽出の正解データ（v1.20）に、アウトカムの定義を加える。加えた正解での検査で、質問の言い回しによって、アウトカムの節が `research_protocol` の返す範囲に入らないことが分かったので、プロトコル内の検索を改める。実測は[検証記録](../validation.md) の 2026-11-20 の節。

1. **正解データは、題材ごとに 1 ファイル**：`tests/fixtures/extraction_gold/*.json`。`eligibility.json`（v1.20、51 項目）に、`outcomes.json`（27 項目）を加える。各ファイルは、質問（`question`）、採点で読む解析のブロック（`analysis_fields`。ドット区切り）、項目の種類（`kinds`）、下限（`minimum.answer_found`、`minimum.analysis_found`）、プロトコルと項目を持つ。`eligibility.json` の `minimum.cohort_found` は `analysis_found` に改める。
2. **アウトカムの正解**：同じ 4 つのプロトコルの、アウトカムの節が挙げるアウトカム、その同定の仕方（どの登録・記録から）、コード、感度分析での別定義、SAP に委ねると書かれた点。質問は「How is each study outcome (endpoint) defined, and from which records, registers or diagnosis codes is it identified?」。解析は `outcomes` と `disease_definitions` を採点する。下限は、回答 0.8、解析 0.6。プロトコルの本文は持たない。
3. **最初の検索に入ることを求めない項目**：付録のコードリストにある項目は、`beyond_first_search: true` とし、`research_protocol` が最初に返す範囲に入ることを求めない（呼出元が、続けて検索して読む）。ほかの判定（見つかる、読み手に渡る、根拠として受理される）は、ほかの項目と同じ。今は 1 項目（研究 49324 の付録のコード）。
4. **スクリプト**：`extraction_eval.py` の `check`、`grade`、`run` は、フォルダの全ファイルを順に扱う（`--gold <ファイル>` で 1 つだけ）。`fetch` と `catalogue` は、全ファイルのプロトコルを、文書ごとに 1 回だけ扱う。`run` は、プロトコルごとに解析を 1 回、質問ごとに質問別回答を 1 回行う。push の前の検査（`check.py` の `gold`）と月ごとのスナップショットのビルドは、両方の正解を確かめる。
5. **質問の文法の語を、検索語にしない**：`search_protocol_text` と `research_protocol` は、質問の語のうち、内容を持たない語（each、from、which、it、are、by、to など。`pdf.QUESTION_WORDS`）を検索語にしない。これまでは、これらの語も内容の語と同じ 1 点で数え、要旨やデータソースの節がアウトカムの節より上に来ていた。呼出元が渡す同義語とコードは、そのまま使う。カタログの検索は変えない。
6. **英語の 1 語は、単純な複数形・単数形でも一致とする**：4 文字以上の英字だけの検索語は、末尾の s の有無を変えた形でも一致とする（outcome と Outcomes）。コード、複数語の句、3 文字以下の語は、書かれたとおりにだけ一致する。不規則な複数形（criterion と criteria）は扱わない。
7. **節の見出しでの一致を重くする**：検索語が節の見出しにあるときの加点を、2 から 4 にする。短い節（「Outcomes definition」の数行）が、同じ語を本文で何度も使う長い節より下に来ないようにする。
8. **順位の低いヒットが、上位のヒットの節の続きのページであるとき**：そのページを、自分の順位ではなく、上位のヒットの直後（直前）に、`continues` 付きで返す（`matched_terms` は自分のもの）。v1.20 の続きのページは、ヒットでないページだけを対象にしていたので、基準の一覧の後半のページが、語を 1 つ含むだけで下位のヒットになり、文字数の上限の外に出ることがあった（要件 5 の変更で、正解データの検査が、研究 49324 の除外基準の 4 項目でこれを捕まえた）。
9. **変えないもの**：`analyze_protocol` の読む範囲、fingerprint、抽出の指示、保存済みの解析と質問別回答。検索の順位は、新しい検索から変わる。
