# v1.7 追加要件：カタログの種類ごとの鮮度、英訳の変更と実行中の抽出、instructions の規則、医薬品名の単語単位の照合

2026-10-08。v1.6 に加える。
根拠は [MCP再レビューと公開・更新方法の調査](../research/202610081041_mcp_review_distribution_updates.md)。

1. **カタログの鮮度は取り込みの種類ごとに判定する**：`catalogue_status` は、全研究のエクスポートと、種別（claims、ehr、registry）のエクスポートそれぞれの最新の取り込みを `exports` に返す。
   `status` が `current` になるのは、全研究のエクスポートがあり、取り込んだすべての種類が期限内のときだけである。`age_seconds` は全研究のエクスポートの経過時間とする。
   種類ごとのエクスポートの日付（ファイル名の `YYYYMMDD_`、無ければ取り込み日）がそろわないときは `snapshot_aligned=false` とし、`browser_refresh_recommended` を真にする。取り込んでいない種別は `missing_source_type_exports` に挙げる（それだけでは `stale` にしない）。
2. **英訳の変更は実行中の抽出も取り消す**：`cache_heading_translations` が別の内容の英訳を保存するときは、その研究のサーバー側抽出を、実行中のものも、終わって未回収のものも取り消す（v1.6 の 3 に加える）。英訳の保存と取り消しの間に待ちを挟まないので、古い読み方の抽出が英訳の後に保存されることはない。
3. **MCP の instructions の先頭に規則を置く**：先頭 512 字に、手順書の場所、上限を超えたら種別と実施国を尋ねること、研究を黙って選ばないこと、未処理のツールをすべて実行すること、予定のデータソースを使用済みとしないこと、原文の引用と物理ページを示すことを収める。手順はその後に置く。
4. **医薬品名の照合は単語の単位で行う**：EMA 医薬品辞書の記録の ATC コードを、カタログがそのコードに付けた名前と結び付けてよいか（v1.1 の 4）は、名前どうしを単語の単位で比べて決める。
   各名前から末尾の塩・水和の語（`SALT_WORDS`）を除き、残った単語の集合の一方が他方を含めば、同じ医薬品とみなす。語順と、`(rDNA)`、`human`、`type A` などの修飾の語の有無は問わない。
   単語の内部の文字列では照合しない。接頭辞の付いたプロドラッグやペグ化体（aprepitant と fosaprepitant、interferon と peginterferon）は別の医薬品とする。
   数字を含む語（型、価数、株）は、両方の名前にあるときは一致を求める（types 16, 18 と types 6, 11, 16, 18 は別）。一方にしか無いときは、無い方を広い名前とみなす。
   配合剤は、両側のすべての成分がそれぞれ対応するときだけ同じとする（v1.0 のまま）。
5. **括弧の中では成分を分けない**：医薬品名の成分への分割（`ingredient_set`）は、括弧の外の区切り（`/`、`+`、`,`、`;`、`and`、`with`）だけで行う。`papillomavirus (human types 16, 18)` は 1 成分、`Icandra (previously Vildagliptin / metformin hydrochloride Novartis)` は配合剤の名前ではなく 1 つの製品名である。
6. **実データでの変化と残る限界**：カタログと辞書の全 553 組（同じ ATC コードを持つ組）のうち判定が変わったのは 6 組で、外れたのは aprepitant と fosaprepitant の 1 組、新たに結び付いたのは表記の違いだけの 5 組である。カタログと辞書の全 5,404 語の展開のうち 30 語が変わった。
   fosaprepitant は、カタログが A04AD12 を aprepitant と名付けているので、制吐薬のクラス（A04）の所属薬から外れる（v1.1 の「名称と成分が食い違う場合は使わない」による。ローカル索引に fosaprepitant を挙げる研究は 0 件）。
   名前の比較だけでは見分けられない組が残る。成分の組を 1 つの文字列で持つ EMA のワクチン名と、その一部の成分のワクチン（4 種混合と 6 種混合）、放射性核種の塩とその結合体（lutetium (177Lu) chloride と lutetium (177Lu) vipivotide tetraxetan）である。この関数は同じ ATC コードを持つ組にしか使わず、ATC はこれらに別のコードを付けているので、資料の側がちょうどその形でコードを誤らない限り結果に表れない。
