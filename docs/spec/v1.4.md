# v1.4 追加要件：呼出元の手順書の配布と、ツールの入力範囲の明示

2026-10-03。v1.3 に加える。

1. **手順書の MCP リソース**：呼出元の手順書 `docs/mcp-workflow.md` を、MCP リソース `ema-rwe://docs/mcp-workflow`（`text/markdown`）として返す。wheel に同梱し（`ema_rwe/docs/mcp-workflow.md`）、チェックアウトでは `docs/` の原本を読む。MCP の `instructions` は、このリソースを先に読むよう案内する。`uvx` で導入した利用者の呼出元も、チェックアウトなしで手順書を読める。手順書は英語のままとする（読み手はツールを操作する呼出元のモデルで、ツール名・項目名・指示文と揃える）。
2. **入力範囲のスキーマ化**：サーバーがすでに検査していた範囲を、ツールのスキーマにも書く。`get_protocol_outline` の `offset>=0`・`limit` 1〜200、`search_protocol_text` の `limit` 1〜30、`read_protocol_text` の `offset>=0`・`max_chars` 1000〜20000。範囲外の値は、これまでどおり受け付けない。
3. **説明の訂正**：`compare_protocols` の説明に、実際の順位付けの順序、`blocks` が置き換える引数と `match_scope=analogous` との併用不可、`check_protocols` が動く条件を書く。`search_studies` の `limit` は `EMA_MAX_COMPARISON_STUDIES` でも切られる。一次判定上限を超えたときの `next_action` は、`facets.conditions` を絞り込みの条件として案内せず、`role=condition` のブロックを AND で加えるよう案内する（`filters` の項目は countries、data_source_types、study_designs だけ）。CLI の `--role` と `search --all-studies` のヘルプを、実際の動作に合わせる。
