# v1.30 追加要件：行末のハイフンで折れた語の引用

2026-11-20。v1.29 に加える。
PDF の本文が行末のハイフンの後で折った語（`ICD-O-` 改行 `3`）を、読み手がつなげて引用すると（`ICD-O-3`）、照合で `EVIDENCE_INVALID`（Quote not found）になっていた（Issue #106）。照合の正規化（`pdf.normalize_quote`）が、空白の並びを消さずに 1 つの空白にまとめるので、PDF 側が `icd-o- 3`、引用側が `icd-o-3` になっていた。手順書は「照合は空白を無視する」と書いていて、実装と合っていなかった。ここには、変わった挙動だけを書く。実測は[検証記録](../validation.md) の「行末のハイフンで折れた語の引用」の節。

1. **ハイフンの直後の空白を詰めて照合する**：照合の正規化で、ハイフンの直後の空白（改行を含む）を消してから、残りの空白の並びを 1 つの空白にまとめる。PDF 側と引用側の両方に同じ正規化をかけるので、折れた語は、つなげて書いても、PDF のとおり空白を入れて書いても一致する。照合はすべてこの正規化を通る（引用の検証、ページの訂正、節のラベルの導出）。
2. **手順書の言い方**：「照合は空白を無視する」を、「空白の並びは 1 つの空白として比べ、ハイフンの直後の空白は無視する」に改める。
3. **変えないもの**：保存する引用の文字列（呼出元が書いたまま）、ハイフンを消して語をつなげる分綴（`hospi-` 改行 `talisation` を `hospitalisation` と書く引用は、これまでどおり一致しない）、ツールの引数と応答の形。
