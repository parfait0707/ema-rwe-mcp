# 医薬品名の照合を単語の単位に変えることの評価と懸念

- 日付：2026-10-08（日本時間）
- 対象：PR #66（`fix/medicine-word-matching`）、spec v1.7 の 4〜6
- 位置づけ：実装者による方式の比較と、独立の判定者（2 回）の結果をまとめた、レビューのための資料。実装は採用してマージしたが、精度が下がる例が 1 件あるので、それを許容してよいかの判断を求める。

## レビュワーに判断してほしいこと

1. 制吐薬のクラス（A04）で検索したとき、所属薬から fosaprepitant が外れることを許容してよいか（「悪化した例」を参照）。
2. 「残る限界」に挙げた 4 つの型を、既知の制限として残してよいか。

実装者の推奨は、どちらも許容することである。理由は「結論」に書く。

## 調査目的

再レビュー（[MCP再レビューと公開・更新方法の調査](202610081041_mcp_review_distribution_updates.md)）は、「`same_medicine("aprepitant", ["fosaprepitant"])` が真になり、fosaprepitant の検索に aprepitant が具体的な検索語として加わる」と指摘した。
この指摘を、個別の薬の名前を書き込まずに、汎用の規則で直すことが目的である。

## 前提と制約

`same_medicine` が決めるのは一つのことだけである。
EMA の医薬品辞書のある記録が持つ ATC コードを、カタログがそのコードに付けた名前と結び付けてよいか、である（spec v1.1 の 4）。
結び付くと、そのカタログの名前が検索語に加わり、クラスで検索したときの所属薬にも入る。
結び付かないときは、「二つの資料がそのコードについて食い違っている」とみなして、コードを使わない。

この関数は、同じ ATC コードを持つ組にしか呼ばれない。
したがって、誤りが結果に表れるのは「名前の判定を誤り、かつ二つの資料が同じコードを持つ」ときだけである。
この前提は、後で残る限界の重さを見積もるときに使う。

検索語の正しさの基準は、AGENTS.md の「クラスと所属薬を同一視しない」「配合剤と単剤を同一視しない」「INN の表記を保つ」である。

## 調査方法

- **全組の比較**：同梱のカタログ（2026-10-01）と EMA の医薬品辞書から、同じ ATC コードを持つ（カタログの名前, EMA の成分名）の組を 553 組作り、方式ごとに判定を比べた。
- **展開の比較**：カタログと辞書のすべての薬の名前とコード（5,404 語）を検索語にして、main のコードと変更後のコードで `expand_medicine` の結果（検索語、カテゴリー語、ATC コード）を比べた。
- **潜在的な誤り**：コードに関係なく、カタログの第 5 レベルの名前（970 件）と EMA の成分の組のすべての組み合わせで、名前が異なるのに同じ薬と判定される組を数えた。
- **独立の判定**：実装者とは別のサブエージェント（opus）が、変わった組と展開のそれぞれを、薬理学の知識と仕様に照らして「改善／同等／悪化」に分けた（2 回。2 回目は括弧の扱いを変えた後の追加分）。

## 選択肢と比較

| 方式 | 553 組での結果 | 採否 |
|---|---|---|
| 旧規則：文字列の部分一致 | aprepitant と fosaprepitant を同じとする。単語の内部まで一致させるため | 指摘の原因 |
| 塩の語を除いた完全一致 | aprepitant の組は外れるが、表記の違いだけの正しい 12 組も外れる（insulin (human) と insulin human (rDNA)、botulinum toxin と botulinum toxin type A、自家培養軟骨細胞の各製品など） | 不採用 |
| 単語の包含（塩の語を除く） | 正しい組をすべて保ち、aprepitant の組だけを外し、表記の違いだけの 5 組を新たに結び付ける | 採用 |
| 上に加え、EMA 側の名前もカンマで成分に分ける | 説明のカンマ（`chondrocytes, in-vitro expanded`）で正しい組が外れる | 不採用 |
| 上に加え、番号の一致を常に求める | 株を書かない広い名前（`influenza, live attenuated`）が H5N1 のワクチンと結び付かなくなる | 不採用 |
| 採用した規則に、括弧の外だけの成分分割と、両方に番号があるときの一致を加える | 単語の包含と同じ判定を保ち、2 価と 4 価の HPV を分ける | 最終案 |

最終の規則は次の三つである。

- 塩・水和の語を除いた単語の集合の一方が他方を含めば、同じ薬とする。語順と修飾の語（`(rDNA)`、`human`、`type A`）の違いは問わない。単語の内部の文字列では照合しない。
- 数字を含む語（型、価数、株）は、両方の名前にあるときは一致を求める。一方にしか無いときは、無い方を広い名前とみなす。
- 名前を成分に分けるときは、括弧の外の区切り（`/`、`+`、`,`、`;`、`and`、`with`）だけを使う。

## 主な発見

### 553 組での判定の変化

変わったのは 6 組で、独立の判定者は 6 組とも新しい規則が正しいとした。

| カタログの名前 | EMA の成分名 | 旧 | 新 |
|---|---|---|---|
| aprepitant（A04AD12） | fosaprepitant | 同じ | 別（プロドラッグで、INN、剤形、承認が別） |
| insulin (human)（A10AB01） | human insulin (rDNA) | 別 | 同じ（語順と製法の表示だけの違い） |
| papillomavirus (human types 6, 11, 16, 18)（J07BM01） | human papillomavirus vaccine [types 6, 11, 16, 18] (recombinant, adsorbed) | 別 | 同じ |
| papillomavirus (human types 16, 18)（J07BM02） | human papillomavirus vaccine [types 16, 18] (recombinant, adjuvanted, adsorbed) | 別 | 同じ |
| 6 種混合ワクチン（J07CA09） | 6 種混合ワクチンの EMA の名前 2 件 | 別 | 同じ |

### 5,404 語の展開の変化

30 語が変わり、判定は改善 17、同等 12、悪化 1 だった。

- **改善の例**：製品名 Actrapid、Gardasil、Cervarix、Hexacima、Infanrix Hexa などが、以前は何にも展開されなかったが、正しいカタログの名前に結び付くようになった。旧名の注記「(previously Vildagliptin / metformin hydrochloride Novartis)」を配合剤と誤認していた製品名（Icandra、GoResp Digihaler、Vantavo）も、正しく展開されるようになった。fosaprepitant と Ivemend は、aprepitant を具体的な検索語に加えなくなった。
- **同等の例**：インスリンやワクチンのクラスに、表記の違うだけの所属薬の名前が加わったもの。ローカル索引で、加わった語だけで新たに当たる研究は 0 件だった。
- **辞書による製品名の展開**（`drug_expansion`）は 1 語も変わらなかった。

### 潜在的な誤り

名前が異なるのに同じ薬と判定される組は、旧規則で 128 組、新しい規則で 111 組だった。
旧規則にだけある 29 組は、すべて別の薬である。新しい規則はこれを分ける。例は次のとおり。

- 鏡像異性体：omeprazole と esomeprazole、ketamine と esketamine、ofloxacin と levofloxacin
- PEG 化体などの派生体：filgrastim と pegfilgrastim、interferon beta-1a と peginterferon beta-1a、somatropin と lonapegsomatropin
- プロドラッグや別の INN：aprepitant と fosaprepitant、morphine と apomorphine、venlafaxine と desvenlafaxine、sirolimus と temsirolimus

今の展開に表れていたのは aprepitant の 1 組だけだが、資料の側がコードを共有した時点で、残る 28 組も誤りとして表れうる状態だった。

## 悪化した例：制吐薬のクラスから fosaprepitant が外れる

- **何が起きるか**：クラス A04（ANTIEMETICS AND ANTINAUSEANTS）で検索すると、以前は所属薬に fosaprepitant が入っていたが、変更後は入らない。
- **なぜ起きるか**：カタログは A04AD12 を aprepitant と名付け、EMA の Ivemend（fosaprepitant）も A04AD12 を持つ。新しい規則では二つの名前は別の薬なので、spec v1.1 の「名称と成分が食い違うコードは使わない」により、Ivemend はクラスの所属薬から外れる。
- **これまで入っていた理由**：旧規則が aprepitant を fosaprepitant の文字列の一部として一致させていたためで、仕様が意図した結果ではない。
- **臨床的な評価**：fosaprepitant は aprepitant のプロドラッグで、制吐薬である。クラスの所属薬としては正しいので、この除外は取りこぼしになる。Ivemend の A04AD12 は誤りではなく、プロドラッグが活性本体とコードを共有する正当な例である。
- **影響の大きさ**：ローカル索引で fosaprepitant を挙げる研究は 0 件、aprepitant は 2 件である。今の検索結果は変わらない。将来、fosaprepitant だけを挙げる研究がカタログに入ると、制吐薬のクラスの検索で取りこぼす。fosaprepitant の名前で直接検索した場合は、辞書の名前の照合で今も見つかる。
- **避ける方法**：クラスの所属薬を決めるときに限り、名前が食い違うコードの記録も含める（spec v1.1 を変える）。そうすると fosaprepitant は残るが、v1.1 の規則が防いでいた「資料の誤ったコードで、別の薬がクラスに入る」ことも防げなくなる。どちらの誤りが起きやすいかを示す実データは、今は無い。

## 残る限界（今回の変更で生じたものと、以前からあるもの）

| 型 | 例 | 新しい規則で | 結果に表れるか |
|---|---|---|---|
| ワクチンの成分の一部と全体 | 4 種混合（diphtheria-pertussis-poliomyelitis-tetanus）と、5 種・6 種混合の EMA の名前 | 新たに同じと判定（5 組） | 表れない。ATC は別のコード（J07CA02 と J07CA09 など）を付けている |
| 放射性核種の塩とその結合体 | lutetium (177Lu) chloride と lutetium (177Lu) vipivotide tetraxetan | 新たに同じと判定（1 組） | 表れない。EMA の記録側にコードが無い |
| 別の単語で付く結合体や派生体 | trastuzumab と trastuzumab emtansine／deruxtecan、epoetin beta と methoxy polyethylene glycol-epoetin beta | 旧規則と同じく、同じと判定 | 今は表れない。以前からの限界で、今回の変更による後退ではない |
| 番号を書かない広い名前 | `influenza, live attenuated` と H5N1 の弱毒生ワクチン | 同じと判定（意図どおり） | H5N1 の名前で検索すると、季節性の弱毒生ワクチンの名前も具体的な検索語に加わる。製品名で検索した場合は main でも同じ結果になる |

最初の二つは、名前の比較だけでは汎用的に見分けられない。
EMA の名前のカンマが成分の区切りなのか説明の区切りなのかは、語彙を持たない限り分からないためである（EMA 側を分ける案は、正しい組を壊したので採らなかった）。
どちらも同じコードを持つ組でしか問題にならず、ATC がそれぞれ別のコードを付けているので、資料の側がちょうどその形でコードを誤らない限り結果に表れない。

## 結論

実装者は、この変更を採用し、悪化の 1 件と残る限界を既知の制限として受け入れることを推奨する。

- **顕在化している変化の収支**：30 語の展開のうち改善 17、悪化 1 で、悪化の 1 件は今の検索結果に影響しない（該当する研究 0 件）。
- **潜在的な誤りの収支**：旧規則にしかない別の薬の組 29 組（鏡像異性体、PEG 化体、プロドラッグ）を分け、新たに生じるのは、ATC が別のコードを付けるので表に出にくい 6 組である。
- **規則の性質**：個別の薬の名前を書き込まず、単語、塩の語、番号、括弧という名前の構造だけで判定する。新しい薬が辞書に入っても、同じ規則がそのまま働く。

悪化の 1 件を避けるには、仕様 v1.1 の規則（名前が食い違うコードは使わない）を緩める必要がある。
実データで fosaprepitant の研究が見つかった時点で、クラスの所属薬に限って規則を見直すのがよいと考える。

## 未解決事項

- Vaxelis（6 種混合ワクチン。成分名が「Haemophilus type b」で、「influenzae」を欠く）は、新しい規則でもカタログの名前と結び付かない。以前からの取りこぼしである。
- 製品名の括弧の外にある会社名や旧名の区切り（`Clopidogrel / Acetylsalicylic acid Viatris (previously ...)`、`... Novartis Vaccines and Diagnostics`）は、今も配合剤と誤認され、展開されない。結果は main と同じで、今回の範囲外である。
- 番号を一方だけが書くときに、広い側の名前を具体的な検索語ではなくカテゴリー語に回す案（H5N1 の例を狭める）は、検討していない。
